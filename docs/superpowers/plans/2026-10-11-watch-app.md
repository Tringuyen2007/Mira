# Apple Watch app — iPhone relay + full watch UI (branch `tri-watch`)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the Plan 4 watch companion into the full Figma "AppleWatch Hi-FI" app: 25 screens in five sections (Setup, Ready & Stop,
Live, Rotation, More incl. a Smart Stack widget), with the iPhone relaying every new watch ⇄ server message.

**Architecture:** Watch ⇄ WatchConnectivity (`WatchWire` flat dictionaries) ⇄ iPhone `WatchBridge` ⇄ `/ws/events` + REST ⇄ server.
The watch never talks to the server. Payload shapes come **only** from `docs/superpowers/plans/2026-10-11-watch-contract.md`;
screen copy/behaviour from the Screens table in `docs/superpowers/specs/2026-10-11-apple-watch-design.md` (referenced, not
re-derived). All decision logic lives in pure Swift — `Mira/Net/` (phone relay, in `MiraNetworking`) and
`MiraWatch/Core/` (watch state machine/maths, a new `MiraWatchCore` SwiftPM target) — so `swift test` covers it on macOS;
SwiftUI/WatchKit/CoreMotion/HealthKit/WidgetKit code stays thin.

**Tech Stack:** watchOS 10 SwiftUI, WatchConnectivity, HealthKit (existing `WorkoutHeartRate`), CoreMotion (`CMMotionManager`,
`CMMovementDisorderManager` behind a flag), WatchKit haptics, WidgetKit (accessory families), App Groups; iOS 17 app; SwiftPM/XCTest.

**Figma board (quick look, `scratchpad/watch-board.png`):** dark-on-light 208×248 cards in five labelled columns —
01 Setup (5), 02 Ready & Stop (4), 03 Live (5), 04 Rotation (5), 05 More (4 incl. Smart Stack) — plus a component sheet
(Status Bar, Button Primary/Secondary, Heart Rate Chip, Haptic Chip). Soft halo/orbit rings behind a big centred element
(button, count, ring, gauge or mascot), status bar on top (accent title left, time right), chips along the bottom.
Exact tokens are pulled in W4 only.

```swift
// WatchRelay.swift — Foundation only
struct WatchRelay {
    /// Server event → zero or more watch messages. Tracks per-set good reps and the last fix_form rep.
    mutating func map(_ event: SocketEvent) -> [WatchWire.ToWatch]
    //  haptic → .haptic(pattern)                breather → .breather(state,bpm,limit)
    //  hr_recovery → .recovery                   rotation_rep/rotation_set → .rotationRep/.rotationSet
    //  sync_progress → .sync(progress, locked)   cue/greeting → .caption(text)
    //  rep(quality "fix_form") → remembers rep index; the next cue within the same set → .formCue(text, rep)
    //  cue id "elbow_drift" → .formCue(text, rep: lastRotationRep)  (always, even without a preceding rep)
    //  rep(quality "good") → goodReps += 1 ; countdown / set change → goodReps = 0
    var goodReps: Int { get }
    /// Live state → snapshot, enriched with goodReps, restRemaining, countdown, exerciseId, isWatchExercise (from plan ids with watch == true).
    func snapshot(_ live: LiveMessage?, plan: [WatchWire.PlanItem]) -> WatchWire.LiveSnapshot
    /// Caption changes in /ws/live (`live.caption`) → .caption once per distinct non-empty text.
    mutating func caption(from live: LiveMessage?) -> WatchWire.ToWatch?
    static func setup(_ r: MeWatchResponse) -> WatchWire.Setup        // nil prefs → WatchPrefs.defaults per key
    static func setupRefreshNeeded(_ event: SocketEvent) -> Bool      // .limitsChanged / .watchFeaturesChanged
    static func socketEvent(_ m: WatchWire.ToPhone) -> SocketEvent?   // button → .watchButton; wrist → .wrist(rotationDeg: deg); syncWindow → .watchSync; else nil
    static func tremorUpload(_ days: [WatchWire.TremorDay]) -> TremorUpload   // keeps the last 14 days only
    static func mergedDevicePrefs(_ current: JSONValue?, taps: String?, arm: String?, doubleTap: Bool?, captions: Bool?) -> JSONValue
    //  object merge: sets watch_taps / watch_arm / watch_double_tap / watch_captions, keeps every other key
}
struct RateGate { init(minInterval: TimeInterval); mutating func allow(_ t: TimeInterval) -> Bool }  // wrist 10 Hz → minInterval 0.1
// WatchBridge (iPhone, @MainActor)
func refreshSetup(api: APIClient?) async   // GET /me/watch → updateApplicationContext(.setup) merged with the latest snapshot context
func handle(event: SocketEvent)            // relay.map → sendMessage (reachable only); setupRefreshNeeded → refreshSetup
private(set) var setup: WatchWire.Setup?   // last fetched, for W8's Settings row
private(set) var watchSetupDone: Bool      // UserDefaults "watchSetupDone"
```
Application context holds a single dictionary and the snapshot already occupies it, so to keep the flat contract `setup`
goes out via `transferUserInfo` (queued, delivered even when the watch app is closed) **and** `sendMessage` when reachable;
the watch treats the latest `setup` as current and caches it in `UserDefaults`. (Document this in NETWORKING.md in W8.)

session active (`phase != idle/done`) && !phoneReachable && !outOfReachDismissed → `.phoneOutOfReach` → `breather` →
`.breather` → `overlay` → phase `countdown` → `.countdown(n)` → watch exercise: `formCue` live && cue is elbow-drift-ish
(rep == nil or cue text contains "elbow") → `.elbowDrift`; `rotationSet` after set end (phase rest) → `.rotationSummary`;
phase active && startZeroed → `.liveTurn`; else `.startPosition` → non-watch: `setDoneUntil > now` → `.setDone`;
phase `rest` → `.recovery`; `formCue.until > now` → `.fixForm`; phase active → `.goodRep` → idle: `.ready`.

## Cross-plan notes (from the server plan — binding)
- New server events have **no `seq`** (`Hub.emit` doesn't add one): every decoder must treat `seq` as optional.
- REST request samples use a `_request` suffix (e.g. `rest_post_me_tremor_request.json`); `rest_patch_patient_limits*.json` mirror therapist-page byte-for-byte. Copy fixtures from `server/samples` when they exist; otherwise create them from the contract.
- Rotation reps also arrive as ordinary `rep` events with `"source": "watch"` and quality `good | partial`; the watch uses `rotation_rep` for the gauge and ignores `rep` events whose `source == "watch"` for the squat counter.
- Elbow drift arrives as `cue {id: "elbow_drift", text}` + `haptic fix_form`.
- `watch_sync` is consumed by the server only (never broadcast back); progress comes from `sync_progress`.
- Maya's seed gains a `forearm_rotation` prescription after squats, so `/me/watch` returns a `watch: true` plan row for the demo.
