# Plan 4 — Apple Watch companion: Ready/Stop, live heart rate, haptic coaching

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A real watchOS companion embedded in the iPhone app (spec §12a "Hackathon" rows): a big **Ready** tap / **Stop** hold, live rep count, heart rate from an `HKWorkoutSession` relayed to the server, and server-driven haptics (good rep, fix form, set done, check-in). The server maps `watch_button` to session commands, emits coaching haptics, and finally persists heart rate.

**Architecture:** New watchOS target `MiraWatch` in `device/ios/Mira.xcodeproj` (bundle `com.mira.app.watchkitapp`, companion of `com.mira.app`, embedded by an "Embed Watch Content" phase). Watch ⇄ iPhone over `WatchConnectivity`; the iPhone's `WatchBridge` (today an empty file) relays `hr`/`watch_button` onto the existing `/ws/events` socket and forwards `haptic` events and live counts back. Server: `HapticCoach` event subscriber (rep/set_done → `haptic`), `watch_button` → `command start|stop` in `main._on_client_event`, `persist.on_event` writes `heart_rate`. The existing standalone mock project `device/watch/` stays untouched (still in the workspace).

**Tech Stack:** watchOS 10+ SwiftUI, WatchConnectivity, HealthKit (`HKWorkoutSession`, `HKLiveWorkoutBuilder`), WatchKit haptics; FastAPI.

Spec: `docs/superpowers/specs/2026-10-11-wire-ios-backend-design.md` §7. Reality check: HealthKit heart rate only flows on a physical watch; the simulator shows "—". Everything else (pairing, Ready/Stop, haptics, rep count) is testable with the paired watch simulator.

### Task 2: `WatchWire` codec + iPhone `WatchBridge`

**Interfaces:**
- `Mira/Net/WatchWire.swift` (pure, Foundation only, compiled into BOTH targets): 
  ```swift
  enum WatchWire {
      // phone → watch
      struct LiveSnapshot: Codable, Equatable { var phase: String; var rep: Int; var repsTarget: Int?; var set: Int?; var setsTarget: Int?; var exerciseName: String?; var hr: Int?; var paused: Bool }
      enum ToWatch: Equatable { case snapshot(LiveSnapshot), haptic(pattern: String), summary(formScore: Int?, goodReps: Int?, repsTotal: Int?) }
      // watch → phone
      enum ToPhone: Equatable { case heartRate(bpm: Double, t: Double), button(name: String), status(workoutActive: Bool) }
      static func encode(_ m: ToWatch) -> [String: Any]; static func decodeToWatch(_ d: [String: Any]) -> ToWatch?
      static func encode(_ m: ToPhone) -> [String: Any]; static func decodeToPhone(_ d: [String: Any]) -> ToPhone?
  }
  ```
  (JSON-safe values only: String/Int/Double/Bool; a `"type"` key; unknown → nil.)
- `Mira/Watch/WatchBridge.swift` (`@MainActor @Observable final class WatchBridge: NSObject, WCSessionDelegate`): `private(set) var isPaired`, `isWatchAppInstalled`, `isReachable`, `lastWatchHR: Int?`; `init(liveSession: LiveSessionStore)`; `func activate()` (guarded by `WCSession.isSupported()`); `func push(_ live: LiveMessage?)` → `updateApplicationContext(WatchWire.encode(.snapshot(...)))` throttled to ≥ 0.5 s and only on change; `func forward(haptic pattern: String)` → `sendMessage` when reachable (ignore errors); `func forward(summary:)`; incoming `didReceiveMessage` → `WatchWire.decodeToPhone`: `.heartRate` → `Task { try? await liveSession.send(.hr(HeartRateMessage(t:bpm:))) }` and `lastWatchHR`, `.button(name)` → `liveSession.send(.watchButton(WatchButtonMessage(name:)))`. Required delegate stubs (`sessionDidBecomeInactive`, `sessionDidDeactivate` → reactivate) included.
- `LiveSessionStore`: `private(set) var haptic: HapticMessage?` + `hapticSeq: Int` set on `.haptic`; `LiveSocket.swift` already decodes `HapticMessage`. `LiveSessionStore.send(_ event: SocketEvent)` convenience for `.hr`/`.watchButton` (today only `.command` is sent; add a generic `send(event:)` that uses `eventSocket.send`).
- `AppState`: `let watch: WatchBridge` created with `liveSession`, `activate()` in init; `var watchPaired: Bool { watch.isPaired && watch.isWatchAppInstalled }`; observe `liveSession.live` and `liveSession.haptic`/`sessionSummary` changes (`withObservationTracking` loop or `onChange` in `MiraApp`) → `watch.push`/`forward`. Settings "Apple Watch tap" toggle enabled when `watchPaired`.
- Add `WatchWire.swift` to the `Mira` target's Sources (pbxproj) — the package picks it up automatically (`Mira/Net`).
